2. ERRO PRINCIPAL DA IA
O backend atual possui lógica semelhante a:
resposta = f"Você perguntou: {request.mensagem}"

Isso apenas repete a mensagem do usuário e NÃO é uma resposta de IA.

Exemplo:
Usuário: Qual é a capital do Brasil?
Nexus atual: Você perguntou: Qual é a capital do Brasil?

Corrija isso. A Nexus precisa realmente processar a mensagem e gerar uma resposta de IA.

Implemente integração real com um modelo/API usando variáveis de ambiente. Não coloque API keys no código. Use .env. Permita trocar o provedor/modelo futuramente.

Trate:
- erros da API;
- timeout;
- indisponibilidade;
- secrets;
- respostas reais.

Não use respostas falsas para fingir que a IA funciona.

Teste:
usuário -> backend -> modelo de IA -> resposta -> frontend.

Detectar categorias como:

- incentivo a atividades perigosas;
